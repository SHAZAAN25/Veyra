VEYRA LOCKED BRANDING ASSETS
==============================

These files are the locked Veyra branding assets.

NORMAL MODE:
- Use the supplied cyan Normal Mode assets.

GAMING MODE:
- Use the supplied crimson Gaming Mode assets.

IMMUTABILITY RULE:
The artwork must not be redrawn, recreated, traced, vectorized into a different
design, recolored, reshaped, distorted, cropped, stretched, filtered, tinted,
glowed, blurred, or replaced.

Use the supplied assets directly.

If a UI implementation conflicts with logo integrity, change the UI implementation,
not the logo.

LOGO INTEGRITY > UI CONVENIENCE

IMPORTANT:
Do not calculate or record hashes from replacement artwork. Hashes must be generated
from these exact supplied files after they are imported into the Veyra repository.

The SVG files supplied here are exact containers preserving the corresponding locked
artwork; do not replace them with a newly reconstructed vector interpretation.
